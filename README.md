# Matzip

뚝섬역 근처 맛집 리스트 샘플 사이트입니다.

## 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 페이지 구조 (히어로, 카테고리 필터, 카드 그리드) |
| `style.css` | 스타일 |
| `data.js` | 맛집 샘플 데이터 |
| `app.js` | 검색 · 카테고리 필터링 로직 |

## 기능

- 카테고리 필터 (한식 / 양식 / 일식 / 카페 / 술집)
- 가게 이름 · 메뉴 실시간 검색
- 평점 · 가격대 · 도보 거리 표시
- 반응형 레이아웃 (모바일 대응)

## 실행

별도 빌드 없이 `index.html`을 브라우저에서 열면 됩니다.

```bash
# 또는 로컬 서버로 실행
python3 -m http.server 8000
# http://localhost:8000 접속
```

> ※ 맛집 정보는 데모용 샘플 데이터입니다.
